# contracts/README.md

This feature exposes no external network API; contracts here document the on-disk artifacts and their expected structure.

- `topics/NN-name.md`: Markdown file following the TopicSkeletonPage schema.
- `data-model.md`: Entity definitions for `TopicSkeletonPage`, `CitationEntry`, `DiagramTemplateBlock`, and `TopicIndex`.

If future programmatic interfaces are added (CLI or HTTP), a machine-readable contract (OpenAPI or CLI schema) will be placed here.
