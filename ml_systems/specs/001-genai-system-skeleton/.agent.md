# GenAI Skeleton Agent: instructions

Purpose
-------

This agent supports generation of skeleton pages that comply with `spec.md` and the repository contracts.

Behavior
--------

- When asked to generate a skeleton page, produce Markdown with frontmatter including: `id`, `title`, `author`, `status: draft`, `source`.
- Follow `specs/001-genai-system-skeleton/spec.md` for required sections and ordering.
- Ensure citation blocks match `contracts/citation_block_contract.md` format.
- Place output under `genai_systems/` and name files using the spec ID or a short slug.

Validation
----------

- Before finishing, run a local checklist:
  1. All required headings present.
 2. Citation blocks conform to the contract.
 3. Frontmatter metadata included.

Notes for maintainers
---------------------

- Prefer small incremental drafts. Large, multi-page outputs should be split and reviewed separately.
- If generation requires code/diagram blocks, reference `src/diagram_blocks.py` and include only templates; do not run code generation without approval.
