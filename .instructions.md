
Workspace Agent Instructions
===========================

Purpose
-------

Provide concrete, practical rules for automated agents and contributors to follow so repository changes remain safe, reviewable, and traceable.

Scope & safety
--------------

- Agents may author or update lesson content, spec drafts, and `genai_systems/` outputs.
- Agents must not make unreviewed edits to `src/` or `tests/`.
- Any change that touches `src/` must include tests in `tests/` and a human reviewer must approve the PR.

Content rules
-------------

- Preserve lesson order and learning objectives listed in `README.md`.
- When generating pages, follow contract files in `specs/001-genai-system-skeleton/contracts/`.

Drafting, PRs and provenance
---------------------------

- Save agent-generated pages as drafts (frontmatter `status: draft`) and place them in `genai_systems/` or the appropriate lesson folder.
- Include `source`, `author`, and `generated_with` in frontmatter. If the content was produced from a prompt, include a short `prompt_summary` field.
- PR description should include:
  - brief summary of generated changes
  - link to the generating prompt (or paste the prompt_summary)
  - list of validation steps the agent performed

Testing & CI
------------

- Agents should run the local test suite before creating PRs that modify code or tests.
- If a proposed change would break CI, open an issue first and request maintainer guidance.

Escalation and large changes
----------------------------

- For structural changes (renaming folders, moving many files, refactors) open an issue and wait for maintainer approval before automating edits.

Examples
--------

Agent PR template (example):

Title: "Draft: genai_systems/02_gmail_smart_compose.md (Auto-generated)"

Body:

- Summary: Generated skeleton for Gmail Smart Compose per spec.
- Origin: `.prompt.md` template — prompt_summary: "Create skeleton page for Gmail Smart Compose".
- Validation: headings present, citation blocks validated, frontmatter included.
- Next: please review and convert drafts to final status when approved.
