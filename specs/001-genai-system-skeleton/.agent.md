# GenAI Skeleton Agent: instructions

Purpose
-------

This agent generates skeleton pages that comply with `spec.md` and the repository contracts. Outputs are intended as drafts for human review and iteration.

Behavior
--------

- Produce Markdown with frontmatter containing: `id`, `title`, `author`, `status: draft`, `source`, `generated_with` and optional `prompt_summary`.
- Follow `specs/001-genai-system-skeleton/spec.md` for required sections and ordering.
- Validate citation blocks against `specs/001-genai-system-skeleton/contracts/citation_block_contract.md`.
- Place outputs under `genai_systems/` and name files using the spec ID or a short slug (example: `002-gmail_smart_compose.md`).

Generation checklist (required)
------------------------------

1. Frontmatter present with required fields.
2. All required headings from `skeleton_page_contract.md` are present and in order.
3. Citation blocks conform to the citation contract.
4. Include a short `prompt_summary` describing the generation intent.
5. Save file under `genai_systems/` and open a PR referencing the prompt and this agent file.

Validation steps (automated where possible)
-----------------------------------------

- Verify frontmatter keys exist.
- Run a heading-order check against `contracts/skeleton_page_contract.md`.
- Validate citation blocks with a simple pattern matcher (author, title, source/date).

Naming and metadata conventions
-------------------------------

- File names: `<spec-id>-<short-slug>.md` or `YYYY-MM-DD-<slug>.md`.
- Frontmatter must include `generated_with` and `source` fields.

Notes for maintainers
---------------------

- Keep outputs small and reviewable; split large topics into multiple drafts.
- If diagram code or runnable snippets are required, include only templates and reference `src/diagram_blocks.py`—do not execute or embed sensitive code without approval.
